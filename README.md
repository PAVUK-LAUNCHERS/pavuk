В одно неясное мне мгновение я задумался.
«А что если наваять лаунчер под мою новую любимую игру, чтобы не пришлось закрывать зомби-клиенты через таск-менеджер, ну и после выхода сразу давались айпишники для переподключения?»

Да, именно так — идея родилась из-за лени заходить в гугл-хром ради страницы для подключения.

## О разработке

Для продвинутых и брезгливых пользователей интернета должен предупредить: **данный продукт был создан не без помощи мощностей Стикса.**

Писалось, придумывалось и дизайнилось всё в качестве прожигания досуга, поэтому делалось в крайне медленном темпе и исключительно по настроению.

Если вдруг так получится, что у вас появилась замечательная идея для этой поделки — Вы знаете куда писать.

## Технические особенности

### Про сетевые вызовы (fetch) на сайте

Сайт-витрина стучится на свой же бекенд ровно за тремя вещами:

- `GET /health` - просто пингует бекенд, чтобы показать статус ONLINE/OFFLINE на странице.
- `GET /api/version` - узнаёт актуальную версию лаунчера и ссылку на скачивание (бекенд сам берёт это из GitHub Releases).
- `GET /snake/session`, `POST /snake/record`, `POST /snake/win` - техническая часть змейки. 

Все эти запросы видно прямо в исходнике `public/index.html`.

### Про блокировку правого клика и выделения текста

В конце того же файла висит небольшой блок:

```js
document.addEventListener('contextmenu', function (e) { e.preventDefault(); });
document.addEventListener('dragstart', function (e) { e.preventDefault(); });
document.addEventListener('selectstart', function (e) { e.preventDefault(); });
```

Это чисто косметика - отключается любым блокировщиком скриптов за секунду, никакой реальной защиты не даёт и ни на что не влияет с точки зрения безопасности.

### Про лаунчеры

Оба лаунчера при клике на сервер открывают `byond://адрес:порт` через `shell.openExternal`. Мониторинг того, запущен ли `dreamseeker.exe`, идёт через официальный `Get-CimInstance` (тот же механизм, что у диспетчера задач), нужен только чтобы скрывать/показывать окно лаунчера в нужный момент. При запуске спрашивает GitHub Releases про новую версию и показывает бейдж - без принудительных обновлений и без блокировки запуска.
